
# Tervilo

**A new approach to general-purpose programming.**

Tervilo is an open-source, statically typed programming language designed for high performance, memory safety, and predictable execution.

It explores a hybrid intent-oriented programming model, combining pure functions, controlled local mutation, and atomic state transitions.

## Philosophy

Programming should be expressive without sacrificing control, safety, or performance.

Tervilo is being designed around four principles:

- **Performance** — Native compilation with efficient execution and minimal overhead.
- **Safety** — Strong static typing, explicit errors, and controlled state mutation.
- **Predictability** — Deterministic execution and well-defined behavior.
- **Simplicity** — Clear syntax and practical abstractions for everyday programming.

## The Language

Tervilo introduces a hybrid execution model where ordinary computations remain straightforward while managed state changes are expressed through explicit intents.

The goal is to make programs easier to understand, reason about, and optimize.

## Development

Tervilo is currently in its early design and research stage.

The language specification, compiler, runtime, standard library, and developer tooling are planned for incremental development.

## Open Source

Tervilo is intended to be developed openly, with an emphasis on correctness, transparency, and long-term maintainability.

Contributions and discussions will be welcomed as the project matures.
